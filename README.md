# Hospital XYZ - T1 (Técnicas de Programación Orientada a Objetos)

Caso: "El Código del Cuidado - Caos en el Hospital XYZ"

## Contenido
- `src/hospitalxyz/Paciente.java` — clase modelo (encapsulamiento y validaciones)
- `src/hospitalxyz/PacienteControlador.java` — controlador (lista de pacientes)
- `src/hospitalxyz/HospitalXYZ.java` — clase principal (Scanner + manejo de excepciones)

## Cómo abrir en NetBeans
1. File > New Project > Java with Ant > Java Application.
2. Nombra el proyecto (ej. `HospitalXYZ`) y desmarca "Create Main Class".
3. Copia la carpeta `hospitalxyz` (con los 3 archivos .java) dentro de `src/` del proyecto creado, reemplazando si pide.
4. Click derecho en `HospitalXYZ.java` > Run File.
